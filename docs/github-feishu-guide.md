# 学术先锋号 · 飞书群机器人与 GitHub 日常维护说明（零基础手把手版）

这份说明专门写给负责日常维护与对接推文的同学。
**全程不需要敲代码、不需要装软件、不需要连服务器**，只要打开电脑浏览器登录 GitHub 网页，点几下鼠标就能完成所有调整。

---

## 一、目前系统已经帮大家配好的默认规则

- **项目仓库地址**：<https://github.com/lankerr/bit-student-feed>
- **公开消息网页**：<https://lankerr.github.io/bit-student-feed/>
- **🌟 可视化推送管理工作台（日常最推荐收藏这个网址！）**：<https://lankerr.github.io/bit-student-feed/manage.html>
  - 打开这个网页就能用鼠标点选星期几、几点推、单双周、寒暑假暂停，右边实时显示未来 4 期排期日历，还能一键下载 Word 完整版、一键复制本期活动清单！
- **自动推送时间**：**每双周的周二早上 09:00**（北京时间，从 **2026-11-24** 起算：11月24日推 → 12月1日单周休息 → 12月8日推，以此类推），方便周四发出「学术先锋号」推文。
- **推送内容范围**：**本周五至下下个周五（共 15 天，含首尾两个周五）的全部已核验活动与通知**（不限类别，学术讲座、竞赛科创、升学就业、实践志愿、校园服务全部收录），卡片底部附带一键下载排好版的 **Word 完整版（`.docx`）**。
  - 例如：`11月24日（周二）` 推送的内容为 **`11月27日（本周五）— 12月11日（下下周五）`** 的活动；下一次 `12月8日（周二）` 推送 **`12月11日 — 12月25日`** 的活动，两期无缝衔接。

## 二、第一次交接准备（只需做这一次，共 2 分钟）

1. **部员注册 GitHub 账号**：
   - 打开 <https://github.com> 点右上角 **Sign up**，用常用邮箱注册一个免费账号，把你的 **GitHub 用户名** 发给学长。
2. **学长开通协作权限**：
   - 学长打开仓库 <https://github.com/lankerr/bit-student-feed/settings/access> → 点绿色 **Add people** → 输入部员的 GitHub 用户名发出邀请。
   - 部员在注册邮箱（或登录 GitHub 后再打开仓库链接）点击 **Accept invitation（接受邀请）**，以后就有修改配置和点运行按钮的权限了！

## 三、日常最常用的 3 个网页操作

### 操作 1：修改推送时间 / 改单双周 / 寒暑假暂停推送

所有时间设置都集中在一个纯中文注释的文件里：**`config/push.toml`**。改完保存后，服务器和 GitHub 会在半小时内自动同步生效！

1. 打开直达链接：<https://github.com/lankerr/bit-student-feed/blob/main/config/push.toml>
2. 点击文件框右上角的 **小铅笔图标 `✏️`（Edit this file）** 进入编辑模式。
3. 对照下面的速查表修改等号右边的数字或文字（**注意保留原有的英文引号和格式，以 `#` 开头的行是中文说明不用管**）：

| 你想调整什么 | 改哪一行 | 怎么改（直接照抄示例） |
| --- | --- | --- |
| **寒暑假暂停自动推送** | `enabled = true` | 改成 `enabled = false`（开学再改回 `true`） |
| **改成每周都推（不分单双周）** | `every_n_weeks = 2` | 改成 `every_n_weeks = 1`（改回双周填 `2`） |
| **改在周三（或其他星期）推送** | `push_weekday = 2` | `1`=周一，`2`=周二，`3`=周三，`4`=周四，`5`=周五，`6`=周六，`7`=周日 |
| **改推送具体几点钟** | `push_time = "09:00"` | 改成 `"12:00"` 或 `"20:00"`（注意保留英文双引号，建议填整点或半点） |
| **新学期重设第一个双周二** | `anchor_date = "2026-11-24"` | 填新学期你想开始推送的那一周日期，如 `"2027-03-02"` |
| **改统计从周几开始、统计几天** | `start_weekday = 5`<br>`span_days = 15` | `5` 代表从本周五开始；`15` 代表共 15 天（本周五到下下周五）。若只看一周（周五到下周五）就填 `span_days = 8` |

4. 改好后，点击页面右上角的绿色按钮 **`Commit changes...`**，在弹出的小框里不用改字，再点一次绿色的 **`Commit changes`** 即可保存！
5. **怎么确认自己没改错？**
   - 点网页最上方的 **`Actions`** 标签页，最上面第一条记录只要在十几秒后变成 **绿色小勾 `✅`**，就说明你的格式完全正确！
   - 点进这条记录，页面上会直接列出一张表格，清楚写明按你的新设置**接下来 4 期分别在哪天几点推送、统计哪几天到哪几天**。

### 操作 2：随时查看本期预览、下载 Word 版、或手动补推一次飞书群

比如推文同学周三临时想再导出一份最新 Word、或者你想自定义某段日期导出活动清单：

1. 打开仓库顶部的 **`Actions`** 页面，在左侧列表点击 **`学术先锋号活动推送`**（直达：<https://github.com/lankerr/bit-student-feed/actions/workflows/pioneer-push.yml>）。
2. 点击右侧的 **`Run workflow`** 按钮，会弹出一个小面板：
   - **第一项（操作模式）**：
     - 选 **`preview_only`**（默认推荐）：**只生成网页预览和 Word 文档，绝对不会往飞书群发消息打扰大家**。
     - 选 **`send_feishu`**：生成后**立刻往 GitHub 绑定的飞书群发一条推送卡片**。
   - **第二、三项（自定义开始/结束日期）**：平时**留空不填**（系统会自动按“本周五～下下周五”算）；只有你想临时查特定日期（比如填 `2026-12-01` 和 `2026-12-15`）时才需要填。
3. 点击绿色的 **`Run workflow`** 按钮，刷新页面等待约 20～30 秒直到圆圈变成 **绿色小勾 `✅`**。
4. 点进这条变绿的运行记录：
   - 页面正中间直接展示排好版的 **本期飞书卡片全文预览**（可以直接复制文字）；
   - 把页面拉到最底下 **Artifacts** 区域，点击 **`学术先锋号活动汇总-Word版`** 即可下载解压得到排好版的 `.docx` Word 文档！

### 操作 3：在飞书群里建机器人，并绑定到系统

如果「学术先锋号」推文组新建了一个飞书群，想让机器人直接往那个新群里推：

#### 第一步：在飞书群里创建自定义机器人（1 分钟）
1. 在电脑端打开目标飞书群 → 点击右上角 **`···`（设置）** → 点击 **「群机器人」** → **「添加机器人」** → 选择 **「自定义机器人」** → 点击添加。
2. 机器人名称可以填：`学术先锋号活动汇总助手`。
3. **安全设置（必看，三选一即可，最推荐第 ① 种）**：
   - **① 推荐：勾选「签名校验」** —— 勾选后旁边会出现一串密钥（比如 `xxxx...`），点复制先记在备忘录里。
   - ② 或者勾选「自定义关键词」—— 关键词请填 **`活动`**（因为机器人每次发送的标题都带有“活动”两个字，填别的词会被飞书拦截拒收）。
   - ⚠️ **不要勾选「IP 白名单」**（GitHub 每次运行的云服务器 IP 不固定，勾了白名单会发不出去）。
4. 复制界面上生成的 **Webhook 地址**（以 `https://open.feishu.cn/open-apis/bot/v2/hook/` 开头的一长串网址），最后一定要点底部的 **「完成」**！

#### 第二步：把机器人地址存进 GitHub 加密保险箱（Secrets）
> 注：GitHub 的 `Settings` 菜单默认只有仓库所有者（学长）能看到。如果你页面顶部没有 `Settings` 按钮，把刚才复制的 **Webhook 地址**（和签名密钥）发给学长按下面两步填一次即可；填进去后是加密隐藏的，任何人都看不到明文，非常安全。

1. 打开仓库顶部的 **`Settings`** → 在左侧边栏向下找到 **`Secrets and variables`** → 点击展开后的 **`Actions`**。
2. 点击右上角绿色的 **`New repository secret`**（如果以前填过想换群，就点已有条目右边的铅笔图标修改）：
   - **`Name`** 严格填全大写：**`FEISHU_WEBHOOK`**
   - **`Secret`** 粘贴刚才飞书群机器人的 `https://open.feishu.cn/open-apis/bot/v2/hook/...` 地址 → 点击 **`Add secret`**。
3. 如果第一步在飞书里勾选了「签名校验」，再点一次 **`New repository secret`**：
   - **`Name`** 严格填全大写：**`FEISHU_SIGNING_SECRET`**
   - **`Secret`** 粘贴飞书给的那串签名密钥 → 点击 **`Add secret`**。
4. 填好后，按上面「操作 2」去 `Actions` → `学术先锋号活动推送` → 选 `send_feishu` 点一次 `Run workflow`，几秒后飞书群里叮咚收到消息卡片，就说明配置成功啦！

## 四、常见问题小贴士（FAQ）

1. **我不小心把 `config/push.toml` 改错了（比如多删了一个引号），系统会崩掉吗？**
   - **完全不会！** 你点保存后，`Actions` 页面会出现红色小叉 `❌`，点进去会用中文提示你是哪一行格式不对，你再点铅笔改回来就行。而且后台服务器带有防呆保护：一旦发现新配置有语法错误，服务器会自动沿用上一次正确的配置，绝不会中断服务。
2. **为什么这周二早上 9 点没有自动发消息？**
   - 因为设置的是 **每双周（每隔两周）** 推一次！比如 `11月24日` 推完后，`12月1日` 是单周轮空休息，`12月8日` 才会推下一期。如果不确定哪一周推，随时去 `Actions` 点进最近一条记录，最下面的表格写明了未来 4 期的准确日期。
3. **如果某个学院新开了公众号，想加进抓取名单怎么办？**
   - 在微信里打开那个新公众号发的任意一篇文章，点右上角 `···` → **复制链接**（`https://mp.weixin.qq.com/s/...`），发给学长在「北理消息站 · 登录维护页」粘贴点一下「添加」，几分钟内服务器就会自动开始长期跟踪这个公众号。
4. **推文同学拿到汇总后还需要人工核对吗？**
   - **需要过一眼原文！** 机器人已经帮你把全校 31 个学院官网、北理就业网和几十个校园公众号筛了一遍，剔除了过期和回顾帖，但有些公众号一推发多篇次条、或者主办方临时改教室/名额，建议推文同学点开卡片里的蓝字标题核对一下具体时间地点再上推文，稳妥第一。
