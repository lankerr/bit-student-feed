4. 新手三步指南（日常怎么改、飞书机器人怎么绑）

    

      

        第一步：平时改时间 / 放假暂停
        
在本页面上方选好新的星期、时间或点「寒暑假暂停推送」，点击绿色按钮「复制配置并去 GitHub 粘贴保存」→ 在打开的页面按 Ctrl+A 全选、Ctrl+V 粘贴 → 点右上角绿色 Commit changes 即可，服务器半小时内自动同步生效。

      

      

        第二步：拿 Word 文档 / 临时补发
        
想直接拿排好版的 Word 发给推文同学，点本页右上角「下载最新完整版 Word」即可；想临时往飞书群手动补推一次，点「打开手动推送页」→ 点右侧 Run workflow → 选 send_feishu 运行即可。

      

      

        第三步：绑定新的飞书群机器人
        
打开目标飞书群 → 右上角设置 → 群机器人 → 添加「自定义机器人」→ 安全设置勾选「签名校验」（不要开 IP 白名单），复制 Webhook 地址与密钥，在 GitHub 仓库 Settings → Secrets → Actions 中填入 FEISHU_WEBHOOK 与 FEISHU_SIGNING_SECRET。
